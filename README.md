# وعـي | WAAY CYBERSECURITY 🛡️
### Human Layer Security Platform for Egyptian Businesses

منصة «وعـي» لبناء خط الدفاع البشري وتدريب موظفي الشركات غير التقنيين على كشف ومكافحة الاحتيال الإلكتروني وهجمات الهندسة الاجتماعية في مصر (إنستاباي، الضرائب، فواتير الموردين).

## ✨ المميزات
- محاكاة تفاعلية واقعية لسيناريوهات الاحتيال المصرية.
- دعم ثنائي اللغة بالكامل (العربية والإنجليزية).
- متوافق 100% مع جميع أحجام الشاشات (Mobile & Desktop Responsive).
- متوافق مع قانون حماية البيانات الشخصية المصري رقم 151 لسنة 2020.
- نموذج حجز مباشر متصل بـ Google Sheets / Excel.
